# TA Portfolio

Personal technical art portfolio and project archive.

| Area | Contents |
| --- | --- |
| [SD-Material](source/SD-Material/) | Substance Designer materials, graphs, and breakdowns |
| [Foliage](source/Foliage/) | SpeedTree projects, vegetation assets, and shaders |
| [Modelling](source/Modelling/) | Blender projects, hard-surface assets, and modelling studies |

| [Level](source/Level/) | Environment art, lighting, level assembly, and optimization |
| [Painting](source/Painting/) | Concept art, texture painting, and visual studies |
| [Simulation](source/Simulation/) | Cloth, destruction, fluids, particles, and procedural simulation |

## Repository Structure

```text
TA_Portfolio/
├─ source/       Editable source projects grouped by discipline
├─ projects/     Complete real-time demos and integrated projects
├─ scripts/      Reusable tools, shaders, and automation
├─ docs/         Technical breakdowns and workflow notes
└─ previews/     Portfolio-ready images, GIFs, and short videos
```

Each finished work should have its own folder and README containing the result,
responsibilities, software versions, technical breakdown, performance data, and
instructions for opening the source project.

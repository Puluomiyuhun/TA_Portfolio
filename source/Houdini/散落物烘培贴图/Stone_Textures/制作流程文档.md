# Houdini 程序化石头地面贴图 —— 制作流程

> 工程文件：`~/Desktop/stone_ground.hip`
> 输出目录：`~/Desktop/Stone_Textures/`

---

## 一、整体思路

从 Houdini 中程序化生成一片石头地面，通过物理模拟让石头自然落地堆叠，最终从顶部正交视角烘焙出三张 2K 贴图，用于 Substance Designer 后续上色处理：

| 贴图 | 用途 | 格式 |
|------|------|------|
| ID Map | 每块石头独立颜色，用于 SD 中分区上色 | 8-bit RGB PNG |
| Height Map | 灰度高度信息，用于凹凸/置换 | **16-bit** 灰度 PNG |
| Normal Map | 顶视图切线空间法线，用于表面细节 | 8-bit RGB PNG |

## 二、节点网络总览

```
[石头形状生成]
stone_base (sphere) → rock_deform (mountain) → fracture_seeds (scatter)
                                                        ↓
                                              fracture (voronoifracture)
                                                        ↓
                                              piece_class (connectivity)
                                                        ↓
                                              pack_stones (assemble)

[散布 + 物理模拟]
scatter_area (grid) → scatter_pts → rand_transform → copy_to_pts ← pack_stones
                                                          ↓
                                                  del_old_name → assign_name
                                                          ↓
                                              merge_rbd_input ← walls_merge (4面墙壁)
                                                          ↓
                                                  rbd_sim (labs::simple_rbd)

[后处理 - 三条颜色管线]
rbd_sim → freeze_frame → unpack_stones
    ↓                         ↓                    ↓
    ↓                   stone_id → id_color    height_color    compute_normals → normal_color
    ↓                         ↓                    ↓                               ↓
ground → ground_black →  merge_id             merge_height    ground_normal → merge_normal
                              ↓                    ↓                               ↓
                           OUT_ID             OUT_HEIGHT                       OUT_NORMAL

[烘焙 - VEX 射线投射]
bake_grid (2048×2048) → bake_xform (Y=50) →┬→ raycast_id     → BAKE_ID
                                            ├→ raycast_height  → BAKE_HEIGHT
                                            └→ raycast_normal  → BAKE_NORMAL

[导出 - /out ROP]
export_id (8-bit) ──┐
export_height (16-bit) ─┤→ export_all (一键导出)
export_normal (8-bit) ──┘
```

### 3.2 石头形状生成

石头形状通过 **Voronoi 碎裂** 得到不规则的碎石外形：

1. **石头基础体** `stone_base`：Polygon 球体 (type=2, freq=4)
2. **山脉变形** `rock_deform`：Mountain SOP，height=0.3, elementsize=0.5，让球体表面凹凸不平
3. **碎裂种子** `fracture_seeds`：在球体表面 Scatter 6 个点作为 Voronoi 切割种子
4. **Voronoi 碎裂** `fracture`：将变形后的球体切成 6 块不规则碎片
5. **连通性分类** `piece_class`：Connectivity SOP，给每块碎片分配 `piece` 属性
6. **打包** `pack_stones`：Assemble SOP，将每块碎片打包为 Packed Fragment

这一步的关键是：一个球体被切成 6 块不同形状的碎片，后续随机挑选这些碎片来填充地面。

### 3.3 石头散布与随机化

1. **散布区域** `scatter_area`：7×7 的 Grid（比地面略小，避免石头贴边）
2. **散布点** `scatter_pts`：40 个随机点
3. **随机变换** `rand_transform`：VEX Wrangle 给每个点分配：
   - **初始高度** `@P.y`：2.0 ~ 8.0（模拟从空中掉落）
   - **随机缩放** `@pscale`：0.3 ~ 1.0（混合大小）
   - **随机旋转** `p@orient`：随机四元数
   - **碎片选择** `i@piece`：0 ~ 5（随机选一块碎片形状）
4. **复制到点** `copy_to_pts`：将 packed 石头按 `piece` 属性复制到各散布点

```vex
// rand_transform VEX
float seed = @ptnum * 13.37;
@P.y = fit01(rand(seed), 2.0, 8.0);
float s = fit01(rand(seed + 1.0), 0.3, 1.0);
@pscale = s;
float rx = fit01(rand(seed + 2.0), 0, 2 * M_PI);
float ry = fit01(rand(seed + 3.0), 0, 2 * M_PI);
float rz = fit01(rand(seed + 4.0), 0, 2 * M_PI);
p@orient = eulertoquaternion(set(rx, ry, rz), 0);
i@piece = int(fit01(rand(seed + 5.0), 0, 5.999));
```

### 3.4 唯一命名

RBD 模拟要求每个 packed primitive 有**唯一**的 `name` 属性。`copytopoints` 会保留原始 assemble 的名字（如 "piece0"），导致大量重复。

解决方案：先用 `attribdelete` 删除旧 name，再用 wrangle 重新分配：

```vex
// assign_name (Run Over: Primitives)
s@name = sprintf("stone_%04d", @primnum);
```

### 3.5 墙壁碰撞体

为防止 RBD 模拟中石头弹飞到画面外，在散布区域四周创建 4 面不可见墙壁：

- 墙壁尺寸：宽度覆盖整个地面（10+），高度 12，厚度 0.5
- 墙壁作为**静态碰撞体**传入 `labs::simple_rbd` 的第二个输入
- 模拟结束后墙壁不会出现在最终输出中

### 3.6 RBD 物理模拟

使用 `labs::simple_rbd` SOP（内置完整的 DOP Bullet 求解器）：

| 参数 | 值 | 说明 |
|------|------|------|
| Ground Plane | 开启 | Y=0 地面 |
| Ground Friction | 1.0 | 高摩擦防滑 |
| Ground Bounce | 0.02 | 极低弹性，石头不会弹跳 |
| Dynamic Friction | 1.0 | 石头间高摩擦 |
| Dynamic Bounce | 0.02 | 石头间极低弹性 |

> **注意**：之前尝试过 `rbdbulletsolver` SOP，但在 Houdini 21 中该节点不会实际运行模拟（输出与输入完全一致）。改用 `labs::simple_rbd` 后模拟正常工作。

模拟 120 帧后，用 `timeshift` 冻结在最终帧。

### 3.7 后处理 —— 三条颜色管线

从 `unpack_stones` 分出三条并行管线，分别为不同贴图着色：

#### ID Map 管线
```
unpack → connectivity → id_color (wrangle) → merge_id (+ ground_black) → OUT_ID
```
- `connectivity`：给每块独立石头分配 `class` 属性
- `id_color`：根据 class 用确定性随机生成唯一颜色

```vex
int cid = i@class;
float r = rand(cid * 17.31);
float g = rand(cid * 31.73);
float b = rand(cid * 53.17);
r = clamp(r, 0.1, 0.9);   // 避免纯黑/纯白
g = clamp(g, 0.1, 0.9);
b = clamp(b, 0.1, 0.9);
@Cd = set(r, g, b);
```

#### Height Map 管线
```
unpack → height_color (wrangle) → merge_height (+ ground_black) → OUT_HEIGHT
```
- 根据 `@P.y` 位置映射灰度值

```vex
float h = fit(@P.y, -0.2, 2.5, 0, 1);
h = clamp(h, 0, 1);
@Cd = set(h, h, h);
```

#### Normal Map 管线
```
unpack → compute_normals → normal_color (wrangle) → merge_normal (+ ground_normal) → OUT_NORMAL
```
- 先用 Normal SOP 计算平滑点法线
- 将世界空间法线转为顶视图切线空间 normal map 编码

```vex
vector n = normalize(v@N);
// 顶视图: tangent=X, bitangent=Z, normal=Y
float r = n.x * 0.5 + 0.5;
float g = n.z * 0.5 + 0.5;
float b = n.y * 0.5 + 0.5;
@Cd = set(r, g, b);
```
- 地面法线固定为朝上 `(0.5, 0.5, 1.0)`

### 3.8 烘焙 —— VEX 射线投射

这是整个流程最关键的技术环节。不使用任何渲染器（Mantra/OpenGL 都有各种问题），而是用 **VEX 射线投射** 直接采样几何体颜色：

1. 创建 2048×2048 的 Grid（ZX 平面），提升到 Y=50 高处
2. 每个网格点向下发射射线 (0, -1, 0)
3. 用 `intersect()` 检测命中，用 `primuv()` 插值采样命中处的 Cd
4. 用 `pointFloatAttribValues()` 批量读取所有点的 Cd 数据

```vex
// raycast wrangle (Run Over: Points)
vector origin = @P;
origin.y = 50;
vector dir = set(0, -1, 0);
vector hit_pos;
vector hit_uvw;
int hit_prim = intersect(1, origin, dir * 200, hit_pos, hit_uvw);
if (hit_prim >= 0) {
    @Cd = primuv(1, "Cd", hit_prim, hit_uvw);
} else {
    @Cd = set(0, 0, 0);  // 未命中为黑色（法线图中为 0.5, 0.5, 1.0）
}
```

> **为什么不用渲染器？**
> - OpenGL ROP：无法完全关闭光照，始终有环境光/渐变干扰
> - Mantra + principledshader：创建节点时导致 Houdini 主线程死锁（crash）
> - Mantra + materialbuilder：渲染结果全白，Cd→Cf 连接在渲染时不生效
> - VEX 射线投射：纯几何计算，无光照干扰，2048×2048 只需几十秒

### 3.9 导出

导出逻辑嵌入在 `/out` 的 Shell ROP 节点中（Pre-Render Script），右键 → Render 即可导出。

- **Height Map**：写 PGM (P5, maxval=65535) → PIL 转 PNG（16-bit 灰度）

一键导出：右键 `/out/export_all` → **Render**

## 五、踩坑记录

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| VEX 中 `$PI` 消失 | JSON 传输时 `$` 被转义吞掉 | 改用 VEX 内置常量 `M_PI` |
| `4@orient` 编译错误 | 四元数前缀应为 `p@` 不是 `4@` | 改为 `p@orient` |
| principledshader 创建后 Houdini 卡死 | 主线程阻塞 | 改用 materialbuilder / 最终放弃渲染器 |
| attribwrangle `class` 参数 | `set(0)` 是 Detail 模式不是 Points | 改为 `set('point')` |
| Grid `orient` 参数 | `orient=0` 是 XY 平面，不是 ZX | 改为 `orient=2`（ZX 平面，Y 朝上） |
| Packed prim `name` 重复 | copytopoints 保留了 assemble 的原始 name | 先 attribdelete 再重新分配唯一 name |
| `rbdbulletsolver` SOP 不模拟 | H21 中该节点输出 = 输入，不执行模拟 | 改用 `labs::simple_rbd` |
| Timeshift 仍跟随当前帧 | 默认表达式 `$F` 未被 `set(120)` 覆盖 | 先 `deleteAllKeyframes()` 再 set |
| Python `exec()` 作用域问题 | 列表推导式/函数无法访问 exec 外层变量 | 避免在 exec 中定义函数，用显式循环 |

## 六、在 Houdini 中预览贴图

1. **切换 Display Flag**：分别点击 `OUT_ID` / `OUT_HEIGHT` / `OUT_NORMAL` 查看 3D 着色预览
2. **查看烘焙结果**：点击 `BAKE_ID` / `BAKE_HEIGHT` / `BAKE_NORMAL` 查看 2D 光栅化平面
3. **视口设置**：按 `D` → Markers → 勾选 Point Colors，确保 Cd 颜色可见
4. **MPlay 查看导出图片**：Windows → MPlay → File → Open，支持 16-bit 灰度

## 七、修改与重新烘焙

如果调整了石头数量/位置/模拟参数：

1. 修改相关节点参数
2. 确保当前帧在 120（模拟结束帧）
3. 到 `/out`，右键 `export_all` → **Render**
4. 三张贴图自动导出到 `~/Desktop/Stone_Textures/`
